# คู่มือตั้งค่า LINE Official Account + LIFF (ฉบับละเอียด)

> สำหรับระบบสารสนเทศโรงเรียน — กลุ่มบริหารกิจการนักเรียน
> เอกสารนี้อธิบายตั้งแต่การสร้าง LINE OA จนถึงการผูกบัญชีผู้ปกครอง พร้อมวิธีแก้ปัญหาที่พบบ่อย

---

## สิ่งที่ต้องเตรียมก่อนเริ่ม

| รายการ | รายละเอียด |
|---|---|
| บัญชี LINE ส่วนตัว | ใช้เป็นผู้สร้าง OA (คนเดียวกับที่ดูแลระบบก็ได้) |
| บัญชี Google | เจ้าของ Apps Script ที่ deploy ระบบ (คนเดียวกับที่ push/deploy) |
| URL Web App ของระบบ | รูปแบบ `https://script.google.com/macros/s/AKfycb.../exec` |
| ข้อมูลโรงเรียนจริง | เบอร์โทรโรงเรียน / ชื่อห้องกิจการนักเรียน (ใช้แสดงใน Flex) |

> **สำคัญ** ถ้า deploy ระบบด้วยบัญชี Google คนละบัญชีกับ LINE OA — ไม่มีปัญหา
> ทั้งสองระบบแยกกัน แต่หน้า LIFF ต้องเปิดผ่าน LINE เท่านั้น

## สถานะการตั้งค่าปัจจุบันของโรงเรียนนี้ (อัปเดตล่าสุด)

| ขั้นตอน | สถานะ |
|---|---|
| 1. สร้าง LINE OA | ✅ เสร็จ — OA `student_affairs` (เบสิค ID `@374rpwus`) |

| 2.6 Channel Access Token | ✅ ได้ token แล้ว → **ขั้นตอนถัดไป: ใส่ในหน้า LINE ของระบบ** |
| 3. สร้าง LIFF app | ⏳ **ยังไม่ทำ — ทำเป็นขั้นตอนถัดไป** (ต้องสร้างใน LINE Login channel — ดูข้อ 3 ด้านล่าง) |

## ขั้นตอนที่ 1: สร้าง LINE Official Account (LINE OA)

1. เปิดเว็บ https://manager.line.biz/ แล้วเข้าสู่ระบบด้วยบัญชี LINE ส่วนตัว
2. คลิก **สร้างบัญชีใหม่ (Create new account)**
   - เลือกหมวดหมู่: **องค์กร / การศึกษา** หรือ "ธุรกิจ/บริการ" (แล้วแต่ตัวเลือกที่มี)
   - ตั้งชื่อบัญชี เช่น **โรงเรียนตัวอย่าง — กลุ่มบริหารกิจการนักเรียน**
   - ตั้งรูปโปรไฟล์, คำอธิบายสั้น ๆ
3. กด **สร้าง** → ระบบจะให้ยืนยันอีเมล (ตรวจกล่องข้อความ) → เสร็จสิ้น
4. จะได้ **LINE OA ID** รูปแบบ `@xxxxxxxx` — จำไว้ ใช้ประชาสัมพันธ์ให้ผู้ปกครองแอดเป็นเพื่อน

> 📌 ยังไม่ต้องตั้งค่าอะไรใน manager.line.biz มากนัก — ขั้นตอนถัดไปจะเชื่อมต่อกับ Messaging API

## ขั้นตอนที่ 2: สร้าง Messaging API Channel (LINE Developers)

Messaging API คือตัวกลางที่ให้ระบบส่งข้อความ (push) ถึงผู้ปกครอง
(ส่วนหน้า LIFF สร้างแยกใน LINE Login channel — ดูขั้นตอนที่ 3)

1. เปิด https://developers.line.biz/console/ → เข้าสู่ระบบด้วย **บัญชี LINE เดียวกับ OA** ในขั้นตอนที่ 1
2. สร้าง **Provider** (ชื่ออะไรก็ได้ เช่น `School Provider`) → กด Create
3. ภายใน Provider → กด **Create a new channel** → เลือก **Messaging API**
4. กรอกแบบฟอร์ม:
   - **Channel name**: เช่น `ระบบสารสนเทศโรงเรียน`
   - **Channel description**: อธิบายสั้น ๆ
   - **Category / Subcategory**: Education / School
   - **Company / Organization**: ชื่อโรงเรียน
   - **Email address**: อีเมลที่ติดต่อได้
   - ติ๊กยอมรับข้อกำหนด → **Create**
5. หน้าถัดไป LINE จะถาม **"เชื่อมต่อกับ LINE Official Account ใด"**
   - ✅ เลือก **OA ที่สร้างในขั้นตอนที่ 1** (สำคัญมาก — ถ้าไม่เลือก ระบบจะสร้าง bot หน้าใหม่ที่ยังไม่เป็น OA จริง)
   - กดยืนยัน

### 6. สร้าง Channel Access Token (หัวใจของการส่งข้อความ)

1. ใน channel ที่สร้าง → แท็บ **Messaging API**
2. หัวข้อ **Channel access token** → กด **Issue** (ครั้งแรก)
3. จะได้ **long-lived token** ขึ้นมา → **กด Copy ทันที** (แสดงครั้งเดียว)
   > ⚠️ ถ้า issue ใหม่ (Reissue) ตัวเก่าจะถูกยกเลิกทันที — อย่ากดเล่น
4. เก็บ token นี้ไว้ในที่ปลอดภัย (จะใส่ในหน้า LINE ของระบบในขั้นตอนที่ 5)

### 7. (แนะนำ) เปิด Webhook

หัวข้อ **Webhook settings** → เปิด **Use webhook** → ปล่อย URL ว่างได้
> ระบบนี้ใช้การ **push** (ระบบส่งหา) ไม่ต้องรับข้อความจาก LINE จึงไม่จำเป็นต้องมี Webhook URL
> การเปิดไว้เฉย ๆ ไม่เสียหาย

## ขั้นตอนที่ 3: สร้าง LIFF App (หน้าให้ผู้ปกครอง)

> ⚠️ **นโยบาย LINE เปลี่ยนแล้ว (2023–2025):** LIFF app สร้างได้เฉพาะใน
> **LINE Login channel** เท่านั้น — สร้างใน Messaging API channel ไม่ได้อีกต่อไป
> (LINE แนะนำให้สร้างเป็น LINE MINI App ในอนาคต แต่ LIFF ยังใช้งานได้ตามปกติ)

1. เปิด https://developers.line.biz/console/ → เลือก **LINE Login channel**
   > 💡 ของโรงเรียนนี้ใช้ channel `student-affairs` (ประเภท LINE Login) ที่สร้างไว้แล้ว
   > — ถ้ายังไม่มี ให้สร้าง channel ใหม่ประเภท **LINE Login** ก่อน
2. ใน channel นั้น → แท็บ **LIFF** → กด **Add**
3. กรอก:
   - **LIFF app name**: เช่น `ระบบผู้ปกครอง`
   - **Size**: เลือก **Full** (ใช้พื้นที่เต็มจอ)
   - **Endpoint URL**: ใส่ URL Web App ของระบบ + `?page=liff`
     ```
     https://script.google.com/macros/s/AKfycb.../exec?page=liff
     ```
     > ต้องเป็น **https** เท่านั้น และลงท้าย `?page=liff` พอดี (ระบบ route หน้านี้ใน `doGet`)
   - **Scopes**: ติ๊ก **`openid`** อย่างน้อย — โค้ด Liff.html ใช้ `liff.getDecodedIDToken()`
     อ่าน LINE userId ต้องมี scope นี้ (`profile` ใส่เพิ่มได้ แต่หน้า LIFF ของระบบไม่ได้ใช้)
4. กด **Add** → จะได้:
   - **LIFF ID** (เช่น `2001234567-abc123` หรือ `1234-abcdef`)
   - **LIFF URL** (เช่น `https://liff.line.me/1234-abcdef`)
5. คัดลอก **LIFF ID** ไว้ — ใส่ในหน้า LINE ของระบบในขั้นตอนที่ 5
   > ผู้ปกครองสามารถเปิดได้ทั้ง LIFF URL หรือผ่านเมนู/QR ของ OA (ขั้นตอนที่ 6)

> 💡 **การ push ข้อความกับ LIFF แยกกันคนละ channel:** push ใช้ Messaging API channel
> (ขั้นตอนที่ 2) ส่วน LIFF ใช้ LINE Login channel — ไม่ยุ่งเกี่ยวกัน ระบบของเราอ่าน
> LIFF ID จากหน้า LINE ของระบบเท่านั้น

## ขั้นตอนที่ 4: ตรวจสอบการ Deploy Web App

1. เปิดโปรเจกต์ Apps Script ของระบบ → **Deploy → New deployment → Web app**
2. ตั้งค่า:
   - **Execute as**: `Me` (เจ้าของโปรเจกต์)
   - **Who has access**: **`Anyone`** ← สำคัญมาก
     > ถ้าเลือก "Anyone with Google account" หน้า LIFF จะเปิดไม่ได้จากนอกบัญชี Google
3. กด **Deploy** → คัดลอก Web App URL
4. ทดสอบ URL ปลายทาง LIFF ในเบราว์เซอร์:
   ```
   <Web App URL>/exec?page=liff
   ```
   - ควรเห็นหน้า LIFF ขึ้นมา แล้วแสดงข้อความ
     *"กรุณาเปิดผ่าน LINE Official Account เพื่อใช้งาน"*
   - ข้อความนี้ = **ทำงานถูกต้อง** (LIFF จะทำงานจริงเฉพาะในแอป LINE)

> 💡 ถ้าใช้ `clasp` ให้รัน `clasp push` ก่อน แล้วจัดการ Deployment ใน
> Apps Script Editor หรือด้วย `clasp deploy` (แบบนี้จะได้ `/exec` ใหม่ทุกครั้งที่ redeploy)

## ขั้นตอนที่ 5: ใส่ค่าลงในระบบ (หน้า "การแจ้งเตือน LINE")

1. เข้าระบบฝั่งโรงเรียน → เมนู **ระบบ → การแจ้งเตือน LINE**
2. ฟอร์ม **การตั้งค่า LINE OA**:
   | ช่อง | ใส่ค่าจาก |
   |---|---|
   | Channel Access Token | ขั้นตอนที่ 2.6 |
   | LIFF App ID | ขั้นตอนที่ 3.4 |
   | แจ้งเตือนคะแนนเพิ่ม | เปิด/ปิดตามนโยบายโรงเรียน (ปิด = แจ้งเฉพาะการหักคะแนน) |
   | ช่องทางติดต่อกลับโรงเรียน | เช่น `โทร 02-XXX-XXXX` หรือ `ห้องกิจการนักเรียน` |
3. กด **บันทึกการตั้งค่า** → การ์ดสถานะควรเปลี่ยนเป็น "พร้อมใช้งาน"

### ทดสอบส่งข้อความจริง

1. ต้องมีผู้ปกครองที่ **ผูกบัญชีแล้วอย่างน้อย 1 คน** (ขั้นตอนที่ 7) — ระบบส่งทดสอบไปยังคนแรกที่ผูก
2. กด **ทดสอบส่งข้อความ** → ผู้ปกครองคนนั้นควรได้รับ Flex Message สีกรมท่า–ทอง
   - ✅ ได้รับ → ตั้งค่าสำเร็จ
   - ❌ ไม่ได้รับ → ดูหัวข้อ "การแก้ปัญหา" ด้านล่าง

## ขั้นตอนที่ 6: ตั้งจุดเข้าใช้งานให้ผู้ปกครอง (เมนู / QR / ลิงก์)

ผู้ปกครองต้อง **แอด LINE OA เป็นเพื่อนก่อน** ถึงจะรับข้อความได้

### วิธี A: Rich Menu (เมนูรูปภาพในแชท OA)
1. ไปที่ https://manager.line.biz → Home → เลือก OA
2. เมนู **Rich menu** → Create → อัปโหลดรูปเมนู (เช่น ปุ่ม "ระบบผู้ปกครอง")
3. กำหนด **Action**: Type = **Link** → ใส่ **LIFF URL** (ขั้นตอนที่ 3.4)
4. ตั้งเป็น **Default rich menu** เพื่อให้แสดงกับทุกคน

### วิธี B: QR Code
1. เปิด **LIFF URL** ในเบราว์เซอร์มือถือ (เปิดได้แค่ใน LINE — แต่ URL ใช้ทำ QR ได้)
2. สร้าง QR จาก URL นั้น (เช่น ผ่านเว็บสร้าง QR) → พิมพ์ติดประชาสัมพันธ์
   > หรือใช้ฟีเจอร์ QR ใน manager.line.biz (ลิงก์ไป LIFF URL)

### วิธี C: แชร์ลิงก์ตรง
- ส่ง **LIFF URL** ให้ผู้ปกครองในแชท LINE — แตะแล้วเปิดหน้า LIFF ขึ้นในแอป LINE ได้ทันที

## ขั้นตอนที่ 7: ผู้ปกครองผูกบัญชี (ทดสอบ end-to-end)

1. ผู้ปกครองเปิด LIFF (เมนู OA / QR / ลิงก์) → หน้าแรก **"นักเรียนของฉัน"**
2. กรอก:
   - **รหัสนักเรียน** (เช่น `26165`)
   - **เบอร์โทรผู้ปกครอง** — ต้องตรงกับที่แจ้งโรงเรียนในระบบเป๊ะ (ไม่รวมขีด/เว้นวรรค)
   - **ตั้งรหัส PIN 4–6 หลัก** (ใช้ยืนยันการยกเลิก/เปลี่ยน PIN)
3. กด **เชื่อมต่อ** → ระบบตรวจความสัมพันธ์ฝั่ง server → สำเร็จ
4. ตรวจสอบฝั่งโรงเรียน: หน้า LINE → ตาราง "ผู้ปกครองที่เชื่อม LINE" มีรายการใหม่ (Active = ✅)
5. ทดสอบเหตุการณ์จริง:
   - บันทึก **หักคะแนน** → ผู้ปกครองได้รับ Flex ⚠️
   - **อนุมัติคำร้องออกนอก** → ได้รับ Flex ✅
   - **ยืนยันหนังสือเชิญ** → ได้รับ Flex 📩
   - **บันทึกเวลาออกจริง** → ได้รับ Flex 🚪
   - บันทึก **เพิ่มคะแนน** → ได้รับเฉพาะเมื่อเปิดการแจ้งเตือนคะแนนเพิ่ม

## การแก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ทดสอบส่งไม่ได้ / HTTP 400 "ยังไม่ได้ตั้งค่า Token" | ไม่ได้บันทึก Channel Access Token | ใส่ token ในหน้า LINE แล้วบันทึก |
| HTTP 401 / 403 | Token ผิด หรือถูก Reissue แล้ว | Issue token ใหม่ → วางแทนของเก่า |
| HTTP 400 "ไม่สามารถส่งถึงผู้ใช้" (Cannot send to user) | ผู้รับยังไม่ได้แอด OA เป็นเพื่อน | ให้ผู้ปกครองแอด OA ก่อน |
| HTTP 429 / เกินโควต้า | เกิน 200 ข้อความ/เดือน (แผนฟรี) | ดูโควต้าที่ Developers → Channel → Usage |
| Flex มาแต่ข้อมูลว่าง/ผิด | ช่องว่างในชีต Config หรือชื่อคอลัมน์ | ตรวจชีต Config (LINE_* values) |
| หน้า LIFF เปิดในเบราว์เซอร์ไม่ขึ้น | ปกติ — LIFF ต้องเปิดในแอป LINE | เปิดผ่านเมนู/QR/Lิงก์ใน LINE |
| LIFF ขึ้น "ยังไม่ได้ตั้งค่า LIFF App ID" | ยังไม่ได้ใส่ LIFF ID ในหน้า LINE | ใส่ LIFF ID (ขั้นตอนที่ 3) แล้วบันทึก |
| ผู้ปกครองผูกแล้วแต่ไม่ได้รับข้อความ | Active=false / ไม่ได้แอด OA / Token ไม่ถูก | ตรวจตารางผู้เชื่อม + สถานะ OA + Token |
| ต้องการเปลี่ยนบัญชีที่ใช้ผูก | ผู้ปกครองยกเลิกเองใน LIFF (ต้อง PIN) | หรือลบแถวในชีต LineBindings ฝั่งโรงเรียน |

## ⚠️ ข้อควรระวังสำหรับนักพัฒนา (บั๊กที่เจอจริงของ Apps Script)

**ห้ามเขียน `//` ในสตริงแบบ double-quote ภายใน `<script>` ของไฟล์ HTML**
เช่น `const url = "https://xxx"` → HTML Service ของ Apps Script จะ**ตัดข้อความหลัง `//` ทิ้ง** กลายเป็น `"https:` → SyntaxError หน้าเว็บพังทั้งหน้า (ปุ่มกดไม่ทำงาน ฟังก์ชัน undefined)

**วิธีที่ปลอดภัย:**
- แยก URL เป็นส่วน ๆ: `"https:" + "//" + "liff.line.me/" + id`
- หรือใช้ template literal (backtick): `` `<a href="https://...">` `` — อันนี้รอด
- ตัวอย่างโค้ดเดิมในระบบ (บรรทัด ~2905 ของ JavaScript.html) ใช้วิธีแยกส่วนอยู่แล้ว

**ตรวจสอบหลังแก้ทุกครั้ง:** push + deploy แล้วยิง URL ใหม่ดูผล (อย่าเชื่อแค่ syntax check ในเครื่อง — บั๊กนี้เกิดเฉพาะตอน Google render)

## เรื่องโควต้า (สำคัญมาก)

- แผน **ฟรี (Communication Plan)**: **200 ข้อความ/เดือน** (ตรวจแผนไทยที่ manager.line.biz)
- **นับตามจำนวนผู้รับ**: ส่ง 1 เหตุการณ์ให้ผู้ปกครอง 1 คน = **1/200**
  - ระบบนี้ใช้ Flex 1 ใบ/เหตุการณ์/ผู้ปกครอง → **ประหยัดที่สุดเท่าที่ทำได้**
  - (การส่ง Reply ไม่นับโควต้า แต่ระบบนี้ใช้ push ล้วน)
- เกินโควต้า → LINE ตอบ error และ **ไม่ส่ง** จนกว่าจะขึ้นเดือนใหม่ หรืออัปเกรดแผน (Light = 5,000/เดือน)
- เช็กยอดที่ใช้: LINE Developers → Channel → **Usage** (มีเมนูดูข้อความที่ส่ง/เดือน)

## สรุปภาพรวมการทำงาน

```
โรงเรียนบันทึกข้อมูล (หักคะแนน/อนุมัติคำร้อง/หนังสือเชิญ/เวลาออกจริง)
        │
        ▼
LineService.gs ตรวจผู้ปกครองที่ผูก (Active=true) + สร้าง Flex Message
        │
        ▼
LINE Messaging API (Channel Access Token) ──► push ถึงผู้ปกครอง 1 ข้อความ/เหตุการณ์
        │
        ▼
ผู้ปกครองเปิด LIFF (?page=liff) ──► ผูกบัญชี (รหัสนักเรียน+เบอร์+PIN)
                                  ──► ดูคะแนน/เกณฑ์/หนังสือเชิญ
                                  ──► ดูข่าวสาร/การแจ้งเตือน
                                  ──► แจ้งลาออก / เปลี่ยน PIN / ยกเลิกการเชื่อม
```

## ⚠️ ห้ามเก็บ Token/Secret ลงในไฟล์ repo (สำคัญมาก)

Channel ID / Channel Secret / Channel Access Token คือ **ความลับ** — ถ้าเผลอ commit
แล้ว push ขึ้น GitHub (โดยเฉพาะ repo สาธารณะ) คนอื่นจะใช้ token ของคุณส่งข้อความ
(เปลืองโควต้า) หรือแอบอ้างระบบได้

**ถ้าเคยเผลอใส่ไว้ในไฟล์ที่ push แล้ว:** ให้ **Reissue** token ใหม่ทันที
(LINE Developers → Messaging API → Channel access token → Issue ใหม่) แล้ววางค่าใหม่
ในหน้า LINE ของระบบ — token เก่าจะถูกยกเลิกทันที
