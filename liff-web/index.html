การแจ้งเตือนล่าสุดของนักเรียน
เลือกนักเรียนเพื่อดูประวัติการแจ้งเตือน
เชื่อมบัญชี LINE กับนักเรียน
กรอกรหัสนักเรียน + เลือกวิธีการยืนยันตัวตน (เบอร์โทรผู้ปกครอง หรือเลขบัตรประชาชนของนักเรียน อย่างใดอย่างหนึ่ง) เมื่อเชื่อมแล้วระบบจะแจ้งเตือนคะแนน คำร้อง และเอกสารของนักเรียนผ่าน LINE ให้อัตโนมัติ
ความปลอดภัยของบัญชี
เปลี่ยนรหัส PIN หรือยกเลิกการเชื่อมต่อของนักเรียนคนใดคนหนึ่ง (ต้องยืนยันรหัส PIN ปัจจุบัน)
เมื่อเปลี่ยน PIN จะต้องกรอกรหัสใหม่เพื่อยืนยันรหัส PIN ใหม่ในช่องถัดไป
